# Hardware work in Velluneo 2.0

Use the [E27 workflow index](hardware/E27/workflow/project-index.md) and the exact PCB toolkit revision recorded there for hardware work. Keep the toolkit in a separate checkout. Keep Velluneo design files, evidence and decisions in this repository.

Read the toolkit's project instructions, existing-project guide, workflow and role documents before taking on a hardware task. Start from the product requirements and recorded decisions. Define a bounded task with acceptance checks, exact inputs and one writer per shared CAD or library file. Record changes, fresh check results and unresolved inputs against the reviewed revision. Assign reviews according to the toolkit and record the actual reviewers and any gaps.

Follow the specification, schematic, placement, routing and release review stages. Record the authorized human's decision against the exact packet before advancing a stage. Preserve existing KiCad sources and scoped rules during adoption. Review a configuration preview against the baseline before applying it.
