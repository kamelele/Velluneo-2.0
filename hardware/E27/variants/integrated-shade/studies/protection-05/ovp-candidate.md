# Precision SCR trigger candidate

The original100V Zener is superseded in this proposal, not relabeled as a precise detector. The independent pin draft is in ovp-candidate.json. Use ATL431BQDBZR (not ATL431LI), a low-current12V Zener, PNP level shifting and a split high-voltage divider. The auxiliary supply is mains-referenced. Keeping the shunt cathode near12V avoids applying the reservoir voltage to its36V-rated cathode. A22kohm base-series resistor prevents a PNP emitter-base short path into the shunt. Keep1kohm gate-to-cathode and100nF gate filtering; use4.3kohm gate feed. No capacitor is added directly at the ATL431 cathode.

Exact MPNS are engineering candidates, not a stocked/assembly-qualified BOM. The intended static trip is approximately129.8V; include reference temperature/cathode-voltage/bias and independent divider drift before judging headroom. Calculation file ovp-screen.json deliberately shows a wider interval than the125–133V design target. At sub-mA initial cathode current the1mA accuracy table does not guarantee these endpoints. Actual VCC loadline, cold gate current, response delay, overshoot, holding and AC-reset behavior remain unclosed. This prevents schematic acceptance; it does not prevent preparing the exact circuit for review.

With the135V and9Vrail screen, the two18kohm2010 resistors each dissipate about0.223W including1% tolerance, below the0.265W125C derating screen before selfheat/mounting verification. Divider halves each dissipate about35mW. Single-part faults must be evaluated separately; nominal ratings are not a component-fault proof. The135V bound is a required outcome of protection coordination, never an already-proven fact.
