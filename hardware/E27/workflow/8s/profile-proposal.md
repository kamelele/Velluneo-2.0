# Proposed JLCPCB process for the 8S power board

Use the toolkit profile `FR4-2L-1oz-routed` as the starting point. The Rev K baseline and the published JLCPCB options support a proposal for a routed 1.6 mm FR-4 board with 1 oz finished outer copper, green solder mask and lead-free HASL. Start with conventional through vias and leave the specific FR-4 laminate and order stackup pending supplier evidence. Verify insulation design inputs against that material. [JLCPCB PCB capabilities](https://jlcpcb.com/capabilities/pcb-capabilities/)

Use Standard PCBA as the quote basis while the mounting side of the new components is open. The Rev K prototype places components on both faces. The published service supports double-sided placement and specifies a 70 × 70 mm minimum for panels, with rails and fiducials. Request a layout-specific quotation once the new PCB and BOM exist. Confirm T1 sourcing, the through-hole scope and the panel. The supplier process for the LED insert is a separate decision. [Rev K handoff](../../Pakiet_prototypu_JLCPCB.md) · [JLCPCB PCBA capabilities](https://jlcpcb.com/capabilities/pcb-assembly-capabilities)

This proposal is based on published service options and existing project evidence. The project owner can review the proposed direction now. Board-specific acceptance, material confirmation and the order decision remain separate records.
