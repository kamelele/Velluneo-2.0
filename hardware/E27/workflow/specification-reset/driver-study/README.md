## Current engineering recommendation

Prioritize primary-side energy buffering in an isolated constant-current base for a common-condition comparison. Retain the simple sinusoidal-power LYTSwitch-5/output-capacitor option as a comparison. The nonlinear LED/buffer study identifies a material current-modulation risk; it does not establish photometric compliance/failure or validate the proposed alternative. Architecture A and the common enclosed base/simple replaceable panel remain unchanged. No quantitative current/flicker target or part is approved here. Investigate UCC28711 as one bounded replacement for the blocked TPS92310 bias/startup path; it retains the same primary-buffered isolated CC base and simple panels. It is a proposal, not a selected or frozen circuit.
