# Execution sources

Archived local execution scripts; their W-relative paths describe the recorded workspace layout and must be adapted to another checkout. Native KiCad10.0.6 and pinned toolkit versions are recorded in check reports. Main design/ is the portable editable deliverable. Historical preparation/build/placement scripts are not bundled as a one-click rebuild because replaying them would reset final routes. route_candidate.py uses the retained pre-route geometry-input.json and checks saved native CAD independently.
