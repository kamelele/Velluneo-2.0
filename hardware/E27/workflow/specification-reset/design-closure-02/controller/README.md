## Fault reset: a finite bound and its real injection limit

TI describes fault stopping, VDD discharge and UVLO restart. With actual switching already stopped, intact R13<=1.021Mohm, CDD<=0.989961uF, nonnegative internal current and no continuing injected bias:

    t_reset <= R13_max*CDD_max*ln(VDD_initial/7.7V)

Starting at35V gives1.530405s; at23V the bound is shorter. This does not rely on an invented minimum IFAULT. For constant injected current J and uniform fault draw I, the exact RC solution uses equilibrium Veq=R13*(J-I). Reset is finite only if Veq is below the selected off threshold. With no guaranteed positive minimum internal draw, the passive guarantee requires **J<7.541626uA** at the7.7V endpoint. At8uA the no-internal-draw case does not reset. A positive injection below that frontier can still make the delay very large. R13-open removes this passive proof. These facts materially constrain auxiliary/leakage pickup and fault reset; they do not establish its actual value on an unbuilt assembly.

The210-case grid sweeps initial9/10/19/23/35V, off7.7/8.5V, injected0–20uA and internal0/95/125uA. Treating95/125uA uniformly across the trajectory is explicitly a sensitivity: TI specifies their table conditions at VDD25V. Fault reset timing is not a lower bound on every retry period, because a real fault can begin arbitrarily close to UVLO and actual charging/current/state timing is unvalidated. Do not infer a guaranteed low average short-circuit power from1.53s.

## Concrete backup direction: TMP708 plus independent regulated bias

ECO-03-candidate.json specifies seven proposed additions and every signal/power pin: TPS7A1650DGNR, TMP708AIDBVR,25.5k setpoint,475k minimum-load bleed,150ohm filter,4.7uF output and0.1uF sensor bypass. U3 OT shunts **U1 NTC physical pin3**, independently of RT1. TI's detailed prose contains a legacy pin1 reference; its actual UCC28711 pin table and the approved graph correctly use pin3. No active intent is changed by this proposal.

TMP708 OT's6V absolute maximum is compatible with the existing NTC pin's5V absolute ceiling; its source minimum5mA sink at0.3V greatly exceeds the125uA NTC source under declared conditions. The5V supply avoids directly attaching a4V-rated TMP302 output to the NTC node. TPS7A1650's60V input range covers the35V design VDD ceiling. A475k bleed ensures at least10uA regulator load even at4.9V and+2.1% resistance; source conditions for ground/enable currents and output-off leakage still matter. These are conditional electrical compatibility checks, not a successful assembled trip test.

The25.5k resistor gives formula nominal85.2739C. Combining an extra±2.1% total resistor budget (initial tolerance and declared100ppm/K drift allocation) with±3C device error yields **81.5374–89.0123C** as a conservative equation screen. There is11.5374K above a hypothetical70C normal sensor and15.9877K below105C at the latest screen, before actual attachment gradient/lag/error. Nominal hysteresis is10C; the source supplies no guaranteed min/max hysteresis or mounted lag, so no bounded numeric restart temperature is invented.

The proposal remains incomplete for application: capacitor DC-bias/aging/temperature/ESR and exact native footprints, input-cap sharing/layout, power-up/off leakage, regulator transient demand and fault pulse sampling must be established. Proposed C5/C6 manufacturer identifiers are candidates with explicit procurement/characterization conditions, not qualified source-confirmed library additions. Sharing the existing0.94uF input bypass avoids silently exceeding the UCC recommended1uF bypass upper limit; a remote regulator requiring another input capacitor must trigger a conscious CDD/startup redesign.

Alternative screening: TMP302B is genuinely pin-selectable70/75/80/85C and lower-current, but its4V absolute output ceiling prevents a direct drop-in connection to the existing5V NTC node. Additional isolation would require a separately sourced circuit. Sensata6700's close-on-rise variant was investigated, but a valid minimum-contact/current guarantee at90–125uA was not established; it is not selected as a dry-circuit replacement. MCP1799 is not selected because the examined line/load accuracy conditions do not establish this microampere-load case. No rejected alternative is declared intrinsically unsafe from those evidence gaps.

The actual TMP708 pin/limit pages3/5 and TPS7A16 pin/limit pages4/6 were rendered and visually inspected, including DNC on the fixed regulator and the unnumbered PowerPAD. Source-page records retain original/PDF/page-image identities externally; no vendor page images are redistributed here. This source check is not a finished footprint or placement validation.

## Executed startup loading and initial-charge checks

The unchanged prior coupled trajectory's pure functions were extracted without running old top-level writers. Only an additional constant bias term was added in this new diagnostic. For the **old worst active4.7ohm configuration**, the existing160-step minimum11.683899V reproduces exactly. Adding an85uA engineering screen gives11.557160V;320 steps give11.557159V. The ~0.127V reduction leaves the conditional10V reserve in that matched case. This is not a new global worst search and does not validate native states, arbitrary extra load or actual sensor/regulator input current.

The backup output capacitors also require initial charging. The separate ideal charge-port model explicitly includes up to6.10uF charged to5.1V (31.11uC), existing CDD and permanent R13 plus30uA controller-start and85uA backup current assumptions. Charge and VDD-port energy conservation are checked. With a hypothetical constant250uA source it reaches19V in0.333085s;500uA gives0.122965s. A constant100uA source cannot cross the assumed electronics-on region. TI's100/250/500uA numbers are specified at VDD0, not as the complete HV I-V law; hence none of those results proves actual startup or a defect. This exposed sensitivity is a reason **not to apply the backup blindly** and not to declare the1s full-lamp criterion passed.
